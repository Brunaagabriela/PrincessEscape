# 👑 Princess Escape

![Princess Escape](./asset/Player1.png)

## About

Princess Escape is a 2D arcade survival game developed with **Python** and **Pygame**.

A young princess is trapped in a haunted forest and must escape from zombie wolves that emerge from the darkness. The player must dodge enemies, survive as long as possible and avoid being captured.

If a wolf reaches the princess, the game ends immediately. Survive until the timer reaches zero to successfully escape and reunite with the prince.

---

## Features

- 2D game developed with Pygame
- Animated player character
- Zombie wolf enemies
- Haunted forest scenario
- Survival gameplay
- Victory and Game Over screens
- Score system
- Keyboard controls
- SQLite database support for scores

---

## Controls

| Key     | Action        |
| ------- | ------------- |
| ↑ ↓ ← → | Move Princess |
| ESC     | Exit Game     |

---

## Objective

Survive the zombie wolves until the countdown reaches zero.

### Victory 👑

The princess successfully escapes the haunted forest and reunites with the prince.

### Defeat 💀

A zombie wolf catches the princess.
